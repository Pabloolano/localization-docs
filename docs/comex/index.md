# COMEX

Módulos `comex` (menú **COMEX**) y `comex_quote` (app aparte **COMEX Cotizador**).

Sirve para agrupar una importación o exportación (OC/OV, facturas, recepciones, DUA y prorrateo de costos) y, aparte, armar un presupuesto de importación a partir de una factura comercial.

<div class="grid cards" markdown>

-   **[Carpetas](carpetas.md)**

    ---

    Importación / exportación, estados, DUA, facturas y costo en destino.

-   **[Cotizador](cotizador.md)**

    ---

    Presupuesto desde PDF/imagen, NCM con IA y costos.

</div>

!!! note "Depósito fiscal"
    El módulo `comex_bonded` (stock no nacionalizado) es una extensión. No se documenta acá hasta que el circuito esté cerrado.

!!! warning
    Claves de IA, DUA reales, RUC y nombres de un cliente no se publican. En las capturas se tapó la compañía.
