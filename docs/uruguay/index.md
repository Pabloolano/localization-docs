# Uruguay

Localización fiscal Uruguay sobre Odoo 19: **CFE** (comprobantes fiscales electrónicos vía DGI / conector), impuestos, diarios y conciliación.

## En esta sección

| Página | Para qué |
|--------|----------|
| [Configuración](configuracion.md) | Compañía, CFE, plan de cuentas, diarios, impuestos |
| [Uso](uso.md) | Emitir CFE, imprimir/enviar, conciliar con DGI |

## Alcance

- Núcleo CFE, PDF del comprobante, conector, consulta RUT, reportes DGI, diferencia de cambio UY.
- No cubre personalizaciones de un cliente (cobranzas bancarias propias, COMEX, etc.).
- No sustituye la documentación nativa de Odoo Accounting: solo lo que agrega la localización.

!!! note
    Los pasos detallados y las capturas se publican en las páginas de Configuración y Uso. Esta portada queda como índice.
